1. Objetivo
Define las especificaciones técnicas e interfaces públicas del IDOS SDK.

2. Filosofía de Infraestructura en el SDK
Los Workers implementan solo lógica de negocio; el SDK gestiona la complejidad de leer/escribir en los directorios de conocimiento (`idos-knowledge/`, `idos-journal/`) de forma transparente dentro del repositorio único.

3. Módulos y Contratos Públicos del SDK
idos-sdk/
├── core/             # Contexto, secrets y logs
├── ai/               # Abstracción de LLMs y RAG
├── data/             # Acceso de lectura/escritura (knowledge + journal)
├── market/           # Datos financieros
├── research/         # Protocolos analíticos
├── portfolio/        # Gestión de posiciones
├── events/           # Bus de eventos
└── notifications/    # Alertas

5. El Módulo de Acceso a Datos (`sdk.data`)
Abstrae la estructura física de los directorios de conocimiento dentro del repositorio único. Devuelve objetos de dominio normalizados. El módulo se divide en dos submódulos que reflejan la separación lógica:

# 📂 ACCESO A CONOCIMIENTO OBJETIVO (idos-knowledge/)
# Recuperación de la ficha y base de conocimiento de una compañía
company = sdk.data.knowledge.company(ticker="MELI")
kb = sdk.data.knowledge.knowledge_base(ticker="MELI")

# 📓 ACCESO A CONOCIMIENTO SUBJETIVO / PROCESO (idos-journal/)
# Lectura del expediente clínico analítico
case_file = sdk.data.journal.case_file(ticker="MELI")

# Recuperación de una oportunidad e hipótesis asociadas
opportunity = sdk.data.journal.opportunity(id="OPP-2026-001")
hypotheses = sdk.data.journal.hypotheses(opportunity_id=opportunity.id)

# Persistencia de evaluaciones y decisiones (se encolan al journal)
sdk.data.journal.save_assessment(assessment_object)
sdk.data.journal.save_decision(decision_object)

11. Definición de Objetos e Interfaces de Dominio (Contracts)
El SDK exporta interfaces Pydantic para las 12 entidades, distribuidas según su directorio de persistencia:

📂 Entidades persistidas en `idos-knowledge/`:
- `Company`
- `KnowledgeBase`
- `Hypothesis`
- `Prediction`
- `Evidence`
- `Rule`

📓 Entidades persistidas en `idos-journal/`:
- `CaseFile`
- `Opportunity`
- `Assessment`
- `Decision`
- `PortfolioPosition`
- `ProvenanceEntry`
