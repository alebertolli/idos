Investment Decision Operating System (IDOS)
Software Design Document (SDD)
Documento 14: Repository & Deployment Architecture - Arquitectura de Repositorios y Despliegue
Versión: 1.1
Estado: Aprobado

1. Objetivo
Define la estructura de repositorios y el modelo de despliegue físico del IDOS.

2. Principios de Despliegue
- Separación Lógica de Concernimientos: Código, configuración, conocimiento objetivo y memoria de decisión se organizan en directorios independientes dentro de un único repositorio.
- Automatización Serverless: Procesos en GitHub Actions.
- Seguridad por Aislamiento: Credenciales inyectadas en tiempo de ejecución.
- Auditoría Nativa en Git: Historial versionado del repositorio único.

3. Modelo de Repositorio Único (Single-Repo)
El IDOS se despliega como un único repositorio Git `idos` con separación lógica de directorios:
```
idos/
├── idos-core/         # Código, SDK, Workers, tests
├── idos-config/       # Prompts, reglas, scoring
├── idos-knowledge/    # Conocimiento objetivo (empresas, datos)
├── idos-journal/      # Memoria de decisión (expedientes, oportunidades)
├── SDD/               # Documentación de diseño
└── .github/workflows/ # CI/CD
```

4. Estructura de Directorios

4.1 `idos-core/`
(Código, SDK, capabilities, workflows, tests).

4.2 `idos-config/`
(Prompt Registry, universe/watchlist.md, email config).

4.3 `idos-knowledge/`
(Memoria analítica objetiva. Empresas, sectores, datos financieros).
idos-knowledge/
└── companies/
    └── <TICKER>/
        └── knowledge_base/ (static/, dynamic/)

4.4 `idos-journal/`
(Memoria de decisión personal. Expedientes, oportunidades, decisiones, aprendizajes).
idos-journal/
├── companies/
│   └── <TICKER>/
│       └── case_file/ (case_file.yml, opportunities/)
├── portfolio/
│   ├── positions/
│   └── watchlist.yml
└── learnings/
    ├── post_mortems/
    └── strategic_notes/

5. Arquitectura de Despliegue en GitHub Actions
Scheduled Runs:
- Daily Refresh: Actualización de datos financieros desde stockanalysis.com y Yahoo Finance (lun-vie 8am UTC).
- Weekly Scout: Screening semanal del universo invertible desde watchlist.md (lun 9am UTC).
- Friday Digest: Generación y envío del resumen semanal vía Telegram/Email (vie 6pm UTC).

Event-Driven Runs:
- CI: Tests automatizados en cada push/PR a main.
