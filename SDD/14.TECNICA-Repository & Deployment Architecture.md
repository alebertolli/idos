Investment Decision Operating System (IDOS)
Software Design Document (SDD)
Documento 14: Repository & Deployment Architecture - Arquitectura de Repositorios y Despliegue
Versión: 1.1
Estado: Aprobado

1. Objetivo
Define la estructura de repositorios y el modelo de despliegue físico del IDOS.

2. Principios de Despliegue
- Separación de Concernimientos: Código, configuración, conocimiento objetivo y memoria de decisión evolucionan en ciclos independientes.
- Automatización Serverless: Procesos en GitHub Actions.
- Seguridad por Aislamiento: Credenciales inyectadas en tiempo de ejecución.
- Auditoría Nativa en Git: Historial versionado en los 4 repositorios.

3. Modelo Multi-Repositorio (Split-Repo Setup)
El IDOS se despliega dividiendo sus componentes en cuatro repositorios Git independientes:

4. Estructura de los Repositorios

4.1 Repositorio 1: `idos-core`
(Código, SDK, capabilities, workflows, tests).

4.2 Repositorio 2: `idos-config`
(Prompt Registry, models.yml, scoring.yml, rules/).

4.3 Repositorio 3: `idos-knowledge`
(Memoria analítica objetiva. Empresas, sectores, datos financieros).
idos-knowledge/
├── companies/
│   └── <TICKER>/
│       └── knowledge_base/ (static/, dynamic/)
└── sectors/ (Fase futura)

4.4 Repositorio 4: `idos-journal`
(Memoria de decisión personal. Expedientes, oportunidades, decisiones, aprendizajes).
idos-journal/
├── companies/
│   └── <TICKER>/
│       └── case_file/ (case_file.yml, opportunities/)
├── portfolio/
│   ├── positions/
│   └── watchlist.yml
└── learnings/
    ├── post_mortems/
    └── strategic_notes/

5. Arquitectura de Despliegue en GitHub Actions
Scheduled Runs:
- Scout, Rebalance.
- Git Queue Sync: Cada 10 minutos procesa la cola `pending_commits` de SQLite y hace push diferenciado hacia `idos-knowledge` o `idos-journal` según la ruta del archivo.

Event-Driven Runs:
- Earnings Trigger, Price Alerts.
