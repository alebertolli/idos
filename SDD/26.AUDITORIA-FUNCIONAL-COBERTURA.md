# Auditoría funcional y matriz de cobertura

Fecha de corte: 2026-10-19. Rama auditada: `codex/clean-platform-implementation`.

Esta matriz inventaría las capacidades del checkout en runtime, workflows,
scripts, configuración, integraciones y dashboard. Distingue pruebas locales de
validación remota y del resultado de inversión. Un test aprobado demuestra el
comportamiento que cubre; no demuestra por sí solo calidad de datos ni que haya
una oportunidad comprable.

## Resultado de validación local

- CI completo del commit `a4e7e6d0`: run [#39336259639](https://github.com/alebertolli/idos/actions/runs/39336259639),
  **success** en Python 3.11 y 3.12. La E2E multi estrategia acotada del
  2026-10-19 está registrada en SDD/25 §8.3.47.

- `idos-core/tests`: 97 archivos de prueba; última ejecución completa antes de
  la extensión contable de Risk Audit: **608 pasaron, 1 omitido, 2 warnings**,
  263,53 s. Después de esa extensión pasaron 16 tests focalizados de función y
  el CLI E2E independiente con fixture privado ficticio. Los warnings de la
  suite completa corresponden a marcas pytest `smoke` y `e2e` sin registrar en
  `pyproject.toml`.
- La ejecución usó un plugin temporal de aislamiento para pytest porque el
  sandbox Windows bloquea directorios creados por `tempfile` y su limpieza.
  No se modificaron pruebas de producto para ocultar esa restricción.
- `exchange-calendars` estaba declarado en `idos-core/pyproject.toml` pero no
  instalado en el intérprete local; se instaló la versión compatible 4.13.2 y
  entonces pasó el test de calendario de mercado.
- Se detectó dependencia accidental del directorio actual al cargar
  `idos-config`. `configured_scout` y `ScoutWorker` ahora resuelven esa ruta
  desde el checkout cuando se ejecutan desde `idos-core`; los tests de
  ScreeningPipeline y ScoutWorker quedaron incluidos en la suite completa.
- Esta suite no ejecuta workflows GitHub, proveedores reales, GitHub Pages ni
  una decisión atribuida al gestor. La evidencia remota histórica se registra
  en `SDD/25.PLAN-E2E-EN-RAMA-DE-PRUEBA.md` §8.3.5–8.3.8.
