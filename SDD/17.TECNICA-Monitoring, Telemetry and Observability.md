Investment Decision Operating System (IDOS)
Software Design Document (SDD)
17: Monitoring, Telemetry & Observability
Versión: 1.1
Estado: Aprobado

1. Objetivo
Definir la arquitectura de monitoreo, telemetría y observabilidad del IDOS, incluyendo el sistema de tracing, notificaciones, y el motor de proveniencia.

2. Principios
2.1 Observabilidad por Defecto: Todo Worker genera automáticamente trazas y run manifests sin configuración adicional.
2.2 Notificaciones Centralizadas: Todas las alertas se canalizan a través del NotificationCenter.
2.3 Trazabilidad Total: Toda conclusión analítica se vincula a su cadena de evidencia mediante el ProvenanceEngine.
2.4 Almacenamiento Local: Toda telemetría se persiste en SQLite. No hay dependencia de servicios externos de observabilidad.

3. Componentes de Telemetría

3.1 Tracer (`idos-core/idos/telemetry/trace.py`)
- Singleton que gestiona la creación de trazas de ejecución.
- `start_run(worker_name: str, metadata: dict | None = None) -> str`: Inicia una nueva traza y retorna run_id.
- `end_run(run_id: str, status: str, tokens_used: int = 0, error: str | None = None)`: Finaliza una traza.
- Las trazas se persisten en la tabla SQLite `telemetry_runs`.
- Utiliza `timezone.utc` (Python 3.11 compatible).

3.2 RunManifest (`idos-core/idos/resilience/checkpoint.py`)
- Creado automáticamente en `BaseWorker.execute()`.
- Contiene: worker_name, timestamps, status, tokens_used, error.
- Integrado con Tracer: al iniciar y finalizar un RunManifest, se invoca `tracer.start_run()` y `tracer.end_run()`.

3.3 NotificationCenter (`idos-core/idos/notifications/__init__.py`)
- Singleton que centraliza alertas al usuario.
- `notify(level: str, title: str, message: str, source: str, actionable: bool = False)`: Envía una notificación.
- Niveles: `info`, `warning`, `error`, `success`.
- Las notificaciones se almacenan en SQLite (tabla `notifications`).

4. Motor de Proveniencia

4.1 ProvenanceEngine (`idos-core/idos/provenance/engine.py`)
- Persiste en la tabla SQLite `provenance_chain`.
- Métodos:
  - `link(conclusion_id, evidence_id, evidence_type, source, metadata)`: Crea un enlace de proveniencia.
  - `get_chain(conclusion_id) -> list[dict]`: Obtiene toda la cadena de evidencia para una conclusión.
  - `get_by_evidence(evidence_id) -> list[dict]`: Obtiene todas las conclusiones que usan una evidencia.

4.2 Esquema de la tabla `provenance_chain`
- chain_id (TEXT PK, UUID v4)
- conclusion_id (TEXT)
- evidence_id (TEXT)
- evidence_type (TEXT: company_yml, wiki, financial_data, market_data, event, external_source)
- source (TEXT: ticker, URL, filename)
- timestamp (TEXT ISO8601, default now)
- metadata (TEXT JSON, nullable)

5. Notificaciones

5.1 Notificaciones Automáticas de Workers
- `BaseWorker.execute()` notifica automáticamente al NotificationCenter:
  - `success`: Worker completado exitosamente.
  - `warning`: Worker completado con errores parciales (e.g., tickers fallidos mientras otros OK).
  - `error`: Worker fallido completamente.
- Los Workers pueden enviar notificaciones adicionales durante su ejecución.

5.2 Notificaciones del Sistema
- Errores de conectividad a APIs externas.
- Alertas de mercado del Market Observatory.
- Decisiones del Board pendientes de revisión humana.
- Límites de costo alcanzados (CostController).

6. Estructura de Datos en SQLite

6.1 Tabla `telemetry_runs`
CREATE TABLE telemetry_runs (
    run_id TEXT PRIMARY KEY,
    worker_name TEXT NOT NULL,
    start_time TEXT NOT NULL,
    end_time TEXT,
    status TEXT NOT NULL,
    tokens_used INTEGER DEFAULT 0,
    error TEXT
);

6.2 Tabla `notifications`
CREATE TABLE notifications (
    notification_id TEXT PRIMARY KEY,
    level TEXT NOT NULL,
    title TEXT NOT NULL,
    message TEXT NOT NULL,
    source TEXT NOT NULL,
    actionable INTEGER DEFAULT 0,
    created_at TEXT NOT NULL,
    acknowledged INTEGER DEFAULT 0
);

6.3 Tabla `provenance_chain`
CREATE TABLE provenance_chain (
    chain_id TEXT PRIMARY KEY,
    conclusion_id TEXT NOT NULL,
    evidence_id TEXT NOT NULL,
    evidence_type TEXT NOT NULL,
    source TEXT NOT NULL,
    timestamp TEXT NOT NULL,
    metadata TEXT
);
