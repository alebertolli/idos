Investment Decision Operating System (IDOS)
Software Design Document (SDD)
Documento 15: IDOS SDK Harness Interface
Versión: 1.0
Estado: Aprobado

1. Objetivo
Definir la interfaz pública del SDK de IDOS y la clase base `AgentBase` para que agentes externos consuman IDOS como arnés.

2. Principios
- Un solo punto de entrada: `from idos.sdk import AgentBase` (y `from idos.sdk import *` para acceso completo).
- Mínimo acoplamiento: el agente externo no necesita conocer la estructura interna de IDOS.
- Hooks explícitos: `on_start`, `on_event`, `on_complete`, `subscribe_to`.
- Telemetría y proveniencia automáticas.

3. Interfaz Pública del SDK

3.1 Facade (`idos.sdk.__init__.py`)
Re-exporta todos los módulos públicos del sistema:
- `idos.data` — Acceso a conocimiento, wikis, company YML
- `idos.market` — Precios de mercado (PriceProvider)
- `idos.ai` — LLM client y capacidades de IA
- `idos.events` — Event Bus
- `idos.resilience` — Self-healing, checkpoints, adaptive routing, cost control
- `idos.portfolio` — Gestión de cartera
- `idos.telemetry` — Tracing y monitoreo
- `idos.notifications` — Notification center
- `idos.provenance` — Provenance engine
- `idos.workers` — Workers disponibles
- `BaseWorker` — Clase base de workers (desde `idos.workers.base`)

3.2 AgentBase (`idos.sdk.agent`)
Clase base para agentes externos:

```python
class AgentBase:
    def __init__(self, name: str, config: dict | None = None):
        """Inicializa el agente con nombre y configuración opcional."""

    def on_start(self):
        """Hook ejecutado al iniciar el agente. Por defecto no-op."""

    def on_event(self, event):
        """Hook ejecutado al recibir un evento del bus. Por defecto no-op."""

    def on_complete(self):
        """Hook ejecutado al finalizar la ejecución. Por defecto no-op."""

    def subscribe_to(self, event_type: str):
        """Suscribe al agente a eventos de un tipo específico."""

    def run(self):
        """Bucle principal del agente. Procesa eventos del bus hasta interrupción."""
```

4. Uso Típico por un Agente Externo
```python
from idos.sdk import AgentBase

class MyAgent(AgentBase):
    def on_start(self):
        print(f"Agent {self.name} started")

    def on_event(self, event):
        print(f"Received: {event}")

agent = MyAgent("my-agent")
agent.subscribe_to("DataIngested")
agent.run()
```

5. Dependencias del SDK
Paquete Python instalable via `pip install -e .` con dependencias en `pyproject.toml`. Compatible con Python 3.11+. No requiere dependencias externas más allá de las especificadas en el proyecto.
